# CalcuRate Frontend

React/Vite frontend for the CalcuRate calculator, saved scenarios, and admin interface.

## Install Dependencies

From the repository root:

```powershell
pnpm install
```

## Start The Frontend

From the repository root:

```powershell
pnpm --dir frontend dev --host 127.0.0.1
```

The UI will be available at:

```text
http://127.0.0.1:5173
```

The frontend expects the backend API to be running at:

```text
http://127.0.0.1:8000
```

## Run Tests

From the repository root:

```powershell
pnpm --dir frontend test
```

## Build For Production

From the repository root:

```powershell
pnpm --dir frontend build
```
